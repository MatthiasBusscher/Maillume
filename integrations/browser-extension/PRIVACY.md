# Browser Extension Privacy

The extension reads only text the user explicitly selects, or the visible currently open message in Gmail or Outlook when no text is selected, after the user invokes the Maillume toolbar action. Chrome's temporary `activeTab` grant is used immediately to inspect accessible frames. The extension has no persistent Gmail or Outlook host permission. It sends the reviewed subject, sender, and message text to the deployment shown in the panel only after **Analyze message** is pressed.

Extension-local storage contains the chosen deployment URL. When the user enables **Remember API key on this device**, it also contains the dedicated, revocable API key and its expiry so the connection survives browser restarts and extension updates; access is restricted to trusted extension contexts. When the option is disabled, the API key and expiry are kept in `chrome.storage.session` for the current browser session.

**Connect this browser** uses a ten-minute device-authorization request. The extension briefly keeps a random device code, pairing ID, deployment, approval URL, expiry, and storage choice in session storage so it can resume polling after the side panel is reopened. The approval page uses the user's existing Maillume account session; account credentials and session tokens never pass to the extension. The server stores only a hash of the device code and bounded connection metadata, not the plaintext API key. The key is returned to the approved extension once.

**Remove connection** clears both key-storage locations and any pending connection request. Captured content is held briefly in service-worker memory for a one-time, tab-specific panel handoff and expires after at most one minute. A session-only recovery descriptor contains only the capture ID, state, and expiry, allowing the panel to request a fresh tab read after service-worker suspension without storing message text or results. Message text and results otherwise remain only in the open panel's memory. No message content or result is written to extension storage. The extension does not use persistent content scripts, background mailbox scanning, cookies, browsing history, advertising identifiers, or analytics.

The selected Maillume deployment controls server-side processing. The official service privacy notice is at `https://maillume.io/privacy`.
